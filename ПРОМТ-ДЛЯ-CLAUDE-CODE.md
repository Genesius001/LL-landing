# Промт для сессии Claude Code

Открыть терминал в папке проекта и запустить `claude`. Скопировать блок ниже целиком.

Предварительно нужно: авторизованный `gh` (`gh auth login`) и настроенный `aws`
(`aws configure`, у ключа должны быть права на Lightsail).

---

```
Проект: статический лендинг Lucky Loki в текущей папке. Без сборки и зависимостей.
Прочитай README.md и DEPLOY.md — там архитектура, юридические решения и целевая схема деплоя.

Сделай четыре вещи по порядку и после каждой покажи результат.

1. GITHUB
Репозиторий https://github.com/Genesius001/LL-landing уже создан и пуст.
Локальный git уже инициализирован, есть один коммит, ветка main, remote origin настроен.
Запушь: git push -u origin main
Если remote не настроен — git remote add origin https://github.com/Genesius001/LL-landing.git
Проверь, что на GitHub видны все файлы, включая assets/ и три .md.

2. LIGHTSAIL
Через AWS CLI создай минимальный инстанс:
- регион us-east-1, зона us-east-1a
- blueprint ubuntu_24_04, bundle nano_3_0 (самый дешёвый)
- имя ll-landing
- launch script возьми из DEPLOY.md, раздел 1 — он ставит nginx, клонирует репозиторий
  и настраивает кеширование и заголовки безопасности

Дождись состояния running, потом:
- создай статический IP с именем ll-landing-ip и привяжи к инстансу
- открой порты 22, 80, 443

3. ПРОВЕРКА
Дай инстансу 2-3 минуты на отработку launch script, затем проверь по статическому IP:
/ /acceptable-use.html /ai-transparency.html /report.html
/robots.txt /sitemap.xml /llms.txt
/assets/demo-before.jpg /assets/demo-after.jpg /assets/legal.css
Все должны отдавать 200. Если что-то не так — зайди на инстанс и разберись,
логи cloud-init в /var/log/cloud-init-output.log

4. ДОКУМЕНТАЦИЯ
Допиши в DEPLOY.md раздел «Доступы» с фактическими значениями:
регион, имя инстанса, статический IP, ID аккаунта AWS, дата создания,
точная команда для выкатки обновления.
Закоммить и запушь.

Ограничения:
- SSH-ключи, .pem и любые креды в репозиторий не коммитить, .gitignore уже это закрывает
- в /var/www/ll-landing не должны попасть .md файлы и папка tools
- ничего не менять в содержимом сайта: формулировки на лендинге и юридических страницах
  выверены, у каждой есть основание в README.md
```

---

## Если Claude Code недоступен

Всё то же руками по `DEPLOY.md`. Единственное, что нельзя пропустить — **статический IP**:
без него адрес поменяется при первой же остановке инстанса.

## Если нужно, чтобы пуш сделал я из этой сессии

Добавьте `Genesius001/LL-landing` в источники сессии — тогда git-прокси начнёт инжектить
креды для этого репозитория, и я запушу сам. AWS в любом случае останется за вами:
API Amazon из песочницы закрыт наглухо.
